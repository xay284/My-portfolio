# My Portfolio

Personal portfolio of Chayma, Data Science engineer.

Built with plain HTML, CSS and JavaScript (no framework, no build step).

## Edit the content
Everything (skills, projects, experience) lives at the top of `script.js`.

## Run locally
Open `index.html` in your browser.

## Deploy (free)
1. Push this folder to a GitHub repository (e.g. `My_portfolio`).
2. Go to vercel.com, sign in with GitHub, click **Add New → Project**, pick the repo and click **Deploy**.
   (Alternative: GitHub repo **Settings → Pages**, deploy from branch `main`.)
